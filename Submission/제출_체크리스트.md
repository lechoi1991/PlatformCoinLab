## 직접 해야 할 일 (순서대로)

1. ⬜ 소개 문서의 제작자 이름 기입, 6장 “추가·개선” 표 확인(본인이 수업 외에 더 한 것이 있으면 추가)
2. ⬜ ContentServer 실행 후 Editor에서 플레이 확인 (서버 ON 45초 / OFF 40초)
3. ✅ 빌드 (2026-11-18): `Builds/Windows`, `Builds/Android/PlatformCoinLab.apk`, `Builds/Web` — 기록은 `Builds/build-log.txt`
   - Android는 한글 경로 문제로 `C:\Build\PlatformCoinLab` 복사본에서 빌드함. 소스를 고친 뒤 다시 빌드하면 이 복사본도 갱신해야 함
4. ⬜ 각 Player 실행 확인 및 캡처 → `Evidence/` (파일명은 [Evidence/README.md](Evidence/README.md))
   - Android는 실기기/에뮬레이터를 구분해 기록
5. ⬜ Profiler 전후 비교 (소개 문서 8장 방법) → 값 기입 + `Evidence/Profiler/`
6. ⬜ 문제 해결 사례 1·2 캡처 (수정 전 화면은 `git show HEAD:Assets/Scripts/Runtime/StageLoader.cs`로 확인 가능)
7. ⬜ 소개 문서의 ⬜ 표시를 실제 결과로 바꾸거나, 못 한 항목은 “미확인/미측정 + 보완 계획”으로 남김
8. ⬜ 패키지 생성:
   ```bash
   powershell -ExecutionPolicy Bypass -File Submission/Tools/Make-SubmissionPackage.ps1
   ```
   → `SubmissionPackage/PlatformCoinLab_Submission.zip`
9. ⬜ (선택) 소개 문서를 PDF로 변환해 함께 제출. 링크로 제출한다면 로그인 없이 열리는지 확인
10. ⬜ 변경 사항 커밋 (소스·빌드·문서가 같은 버전인지 확인)
